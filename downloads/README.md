# 下载成品

这里放可直接运行的 CodexMeter 成品，适合不想研究源码、只想直接使用的人。

## 当前版本

- Windows x64 便携版：`CodexMeter-v0.1.0-win-x64/CodexMeter-v0.1.0-win-x64-portable.exe`

## 使用方式

双击 `.exe` 即可运行，不需要先安装开发环境。

如果 Windows 提示未知发布者，这是因为当前版本还没有代码签名证书。确认文件来自本仓库后再运行。
