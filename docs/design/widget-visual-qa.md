# 悬浮球视觉验收记录

## 目标

悬浮球采用深蓝玻璃卡片 + 左侧额度圆环 + 右侧两条额度进度条的紧凑布局，参考用户确认的横向展开效果。

## 当前验收结论

- 左侧圆环、右侧信息卡片和重叠关系已经按紧凑横向方案收敛。
- 5 小时额度和 7 天额度进度条均可见，颜色区分为蓝色和紫色。
- 右侧信息区减少了多余留白，底部重置时间和重置卡信息没有裁切。
- 字号经过放大，主信息可读性优先于装饰效果。
- 点击交互由测试覆盖，避免展开区域遮挡悬浮球点击。

## 自动化覆盖

- `tests/widgetInteraction.test.ts` 覆盖点击和拖拽判定。
- `tests/widget-orb.spec.ts` 覆盖展开尺寸、两条额度进度条、重置信息和刷新状态。
- `tests/quota-footer.spec.ts` 覆盖主页面额度条右侧百分比字号。

## 后续视觉验收建议

每次改悬浮球样式后，至少做三项检查：

1. 低额度、高额度、未连接三种状态截图。
2. 悬浮球点击展开和收起，确认没有透明区域挡住点击。
3. 主窗口和悬浮球同时打开，确认视觉风格一致。
