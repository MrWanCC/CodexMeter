CodexMeter Hardware

ESP32-C3 小屏一键刷机

用 Chrome 或 Edge 打开本页，插入 ESP32-C3，点击安装即可刷入 CodexMeter OLED 小屏固件。 固件同时包含蓝牙、HTTP 推送和 Wi-Fi 配网页。

刷机步骤
  1. 用 USB 线连接 ESP32-C3。
  2. 点击下方 Install 按钮，选择对应串口。
  3. 确认安装固件，等待刷入完成。
  4. 刷完后搜索 Wi-Fi 热点 CodexMeter-Setup，打开 http://192.168.4.1 配网。

Web Serial 需要 HTTPS 环境，仅支持 Chrome / Edge 等 Chromium 浏览器。 如果浏览器看不到设备，请按住开发板 BOOT 键后重新插入 USB，或更换数据线。
